Aerodynamics

Vortex Shedding Behind Circular and Elliptical Cylinders

Transient 2D wake simulations that compare the lift oscillations of a circular and an elliptical cylinder.

Category
Aerodynamics
Tools
Ansys Fluent
Context
Arizona State University

Overview

External flow past a 2D cylinder was solved transiently to capture vortex shedding. The mesh resolution and time step were set up carefully, and the lift force history was compared between the circular and elliptical sections.

Setup and method

  • Set up the simulation, mesh resolution and time-step size, then run and post-process.
  • Contours of y-velocity, stream function and vorticity magnitude.
  • Lift force vs time for the circular cylinder and for two elliptical-cylinder runs.
  • Check the reliability of the set-up before drawing conclusions about the flow.

Results

Lift oscillation amplitude and period: circular cylinder 0.01261 N and 6.964 s; elliptical cylinder run 1, 0.0544 N and 13.22 s; run 2, 0.0111 N and 12.33 s.
